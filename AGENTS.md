# Marketplace fixture MCP

- Node.js 24 ESM TypeScript service. Keep the build output entry at `dist/index.js`.
- Owned app files: `package.json`, `package-lock.json`, `tsconfig.json`, `tsconfig.test.json`, `src/**`, `tests/**`, `README.md`, `AGENTS.md`, and `.gitignore`. Coordinate container/CI changes with their owner; do not rewrite unrelated files.
- Validate tool inputs strictly with Zod and return malformed arguments as JSON-RPC `InvalidParams`. Preserve the public names `marketplace_search`, `marketplace_fetch`, and `marketplace_status` and the versioned consumer listing contract.
- The fixture backend is synthetic only. Never fetch a supplied listing URL; serve only on trusted private networks. Any `Origin` header is rejected until browser access has an explicit origin policy.
- Backends expose a bounded non-empty `name`; provider failures must use validated `ProviderError` values. Search/fetch backend calls receive an abort signal and obey the configured deadline, while recognizing arbitrary promises cannot be forcibly cancelled.
- Browser runtime uses one serialized persistent-profile browser; never store Facebook credentials, log cookies/localStorage/headers/page content/profile contents, or expose CDP. Browser work must honor the abort signal. The fixture backend stays the default and Facebook selection is opt-in.
- The Facebook session probe only classifies session state. A separate credential login (`src/facebook-login.ts`) may submit optional environment-supplied credentials for a plain login requirement, then wait for the out-of-band mobile approval by polling that same classification. Its single in-flight attempt is service-scoped, survives a search deadline, and is aborted and awaited on shutdown; each search waits only within its own backend budget. Approval can land on any authenticated same-origin page; the login navigates to Marketplace to verify before reporting success, and only the backend's confirming probe records `session_usable`. It never solves or bypasses a captcha or checkpoint and never automates 2FA: those states are reported so the manual re-auth flow takes over. Credentials are environment-only — never stored, logged, returned, or persisted separately; passwords are submitted unchanged, and they are read only when the Facebook backend is selected, so a fixture deployment never touches them. The resolved login URL must be same-origin with the configured base, not merely an approved origin. Ambiguous or failed probes remain `session_unknown`, never usable; Marketplace search fails closed on `session_unknown`. Keep origin injection an internal test seam, and never log page content, cookies, storage, headers, or form values.
- Facebook item IDs come only from valid extracted item URLs; never synthesize one. Search-card `state` is never `active`. Location slugs must come from configured markets and are never guessed. Unknown layouts are typed upstream errors, never empty success. Search is one page, without scrolling or pagination. Fetch accepts a listing id or canonical Marketplace item URL; it extracts the id and rebuilds the URL from the configured base, never navigating to a caller-supplied origin. Fetch uses the same fail-closed auth/checkpoint path as search; removed or unavailable listings are `NOT_FOUND`, and fetch may return `state: active`. Do not add a second browser or auth subsystem.
- Facebook fixture pages are synthetic and sanitized. Browser tests block all network access and must make zero Facebook requests. Never log page content, card text, hrefs, image URLs, extracted records, cookies, or storage; logs may contain only error names/codes and counts.
- Re-auth leases own the profile exclusively; admin and viewer bind to loopback only; ephemeral tokens are never logged or persisted; never automate 2FA or an interactive challenge, and never persist credentials; teardown is bounded and idempotent; assessments reset to `session_unknown` and never become usable automatically.
- Development checks: `npm ci --ignore-scripts`, `npm run build`, `npm run typecheck`, `npm test`, and `npm run lint`.
